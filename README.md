# 订单通新首页

订单通 iReve 的响应式产品首页，使用原生 HTML、CSS 与 JavaScript 实现。

在线访问：https://caohongbocaohongbo.github.io/dingdantong-new-homepage/

## 页面内容

- 产品介绍、AI 场景、版本与报价。
- Logo 汇聚、输入提示轮换、统计数字递增及对话打字动效。
- 登录弹窗与响应式布局。

## 本地预览

直接打开 `index.html`，或在当前目录启动静态服务器：

```sh
python3 -m http.server 8000
```

随后访问 `http://localhost:8000`。

## 发布

GitHub Pages 从 `main` 分支根目录发布；更新页面资源后提交并推送即可。

## 功能范围

当前为前端展示页面，真实登录、验证码发送和微信授权尚未接入。
